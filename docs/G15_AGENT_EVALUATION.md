# G15 — Agent Evaluation

> **Internal frozen evaluation — NOT an external benchmark.** The metrics measure
> the PLANNER + POLICY + EXECUTOR (does it plan validly, pick the right tools,
> respect dependencies, complete the mission, keep evidence + verification, avoid
> forbidden actions, recover from failure, stop early when appropriate, avoid
> pointless calls), **not** model accuracy. Every rate is reported **with its N**.
> No claim of "state-of-the-art", "fully autonomous", "hallucination-free", or
> "real-time".

The machine-generated report is regenerated by `run_agent_eval.py`:

- `evaluation/agent/reports/G15_AGENT_EVALUATION.md` — human-readable
- `evaluation/agent/reports/G15_AGENT_EVALUATION.json` — full rows + metrics
- `evaluation/agent/reports/latest.json` — same as the JSON

```bash
.venvs/satquery/Scripts/python.exe evaluation/agent/run_agent_eval.py            # plan phase (all 50), fast
.venvs/satquery/Scripts/python.exe evaluation/agent/run_agent_eval.py --exec 2   # + real-model exec sample
```

## Dataset — `evaluation/agent/frozen_missions.json`

**50 missions**, 5 categories × 10:

| category | what it probes |
|----------|----------------|
| `single_step` | VQA / grounding / scene — one specialist, finish after it + verify |
| `temporal` | change / semantic-change / change-regions on a co-registered pair |
| `optical_sar` | joint CROMA representation on a paired S2 + S1 |
| `multi_step` | investigations: change → regions → grounding → optical+SAR → cross-check → verify |
| `adversarial` | unsupported task · missing 2nd image · missing SAR · misregistered CRS · corrupt GeoTIFF · object absent · ambiguous · out-of-scope · wrong-tool-named · unbounded ask |

Each mission encodes **what a correct agent should do** — `expected_task_family`,
`expected_tool_set`, `expected_order_constraints` (`A < B`),
`expected_termination_behavior`, `expected_failure_behavior` — **never the exact
answer**.

## Metrics (13, each with N)

**Plan phase** (all 50, no models): `PLAN_VALIDITY_RATE` (supported missions),
`FAILED_PLAN_RATE`, `ADVERSARIAL_CORRECTLY_HANDLED_RATE`,
`TOOL_SELECTION_ACCURACY`, `TASK_ORDER_CORRECTNESS`, `DEPENDENCY_VALIDITY`.

**Exec phase** (bounded real-model sample): `MISSION_COMPLETION_RATE`,
`EVIDENCE_PRESERVATION_RATE`, `VERIFICATION_PRESERVATION_RATE`,
`FINAL_ANSWER_FACTUAL_CONSISTENCY`, `UNSUPPORTED_ACTION_RATE` (forbidden/illegal
tool calls that RAN / total tool attempts), `RECOVERY_RATE` (recoverable-failure
missions that still reached a valid final state), `EARLY_STOP_EFFICIENCY` (over
missions where stopping early is *appropriate*), `UNNECESSARY_TOOL_CALL_RATE`
(completed specialist calls that did not contribute to mission completion / total
calls). Plus `avg_tool_calls`, `avg_replans`, `avg_latency_s`, replan-reason
counts.

**Baseline vs agent** on the multi-step missions: how many of the required
specialists each approach actually selects and runs. The deterministic `/analyze`
routes to exactly one; the agent plans and runs the several the mission needs.

## Failure & recovery examples

Drawn from the exec + policy rows:

- **Misregistered CRS pair (ad‑04 family)** — planner proposes a temporal plan
  from "2 images + change"; the **policy layer** rejects it on `7_geospatial`
  once real co‑registration is checked pre‑plan. `run_investigation` returns via
  the visible deterministic fallback with `resolution.qualifier =
  PLANNER_UNAVAILABLE` and an `AGENT FALLBACK: PLAN_REJECTED` warning.
- **Missing SAR (ad‑03 / os‑missing family)** — the MISSING_INPUT pre‑check
  fires before `OPTICAL_SAR_ANALYSIS` (`sar_ref == opt_ref` / not 2‑band);
  CROMA is **never called**, a `MISSING_INPUT` replan is recorded, and the
  synthesis states "Optical+SAR analysis was not performed".
- **Identical T1/T2 (tm‑10)** — `run_temporal_change` reports
  `changed_fraction ≈ 0` → `NEW_EVIDENCE` replan skips region extraction /
  grounding / SAR, `early_stopped = True`, mission concludes "no meaningful
  change" without fabricating grounded regions.
- **Object absent (ad‑06 family)** — grounding returns no box; synthesis
  reports the object was not localized, no fabricated bbox, plan still
  finalizes.
- **Unsupported task (ad‑03 "compare optical and SAR" with 2 optical images)** —
  policy rejects on `5_modalities`; deterministic `/analyze` also cannot handle
  it → `phase=FAILED, mode=ask-fallback`. Counted as a **valid terminal state**
  (an honest refusal), not a completion failure.

## Limitations

- Local demo fixtures only; not confirmed on non-demo imagery.
- `RuleBasedPlanner` is the default; `LlmPlanner` (local Qwen2-VL-2B text-only) is
  opt-in and always falls back — the eval's second (LLM) arm is future work.
- No labelled ground-truth plan per mission yet — `expected_*` constraints, not a
  single gold plan.
- 4 GB-VRAM fit **UNVERIFIED**. No confidence values. Frozen model stack unchanged.
