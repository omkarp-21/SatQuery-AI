# Evaluation

| Dir | Contents |
|-----|----------|
| `datasets/` | Held-out imagery + query sets (gitignored if large). |
| `cases/` | One YAML/JSON per scenario: query, inputs, expected answer, rubric. |
| `metrics/` | Metric implementations (accuracy, IoU, grounding, calibration). |
| `scripts/` | `run_suite.py` and helpers. |
| `reports/` | Generated run reports (gitignored). |

See [`../docs/11_EVALUATION_PLAN.md`](../docs/11_EVALUATION_PLAN.md).
